Security Officer Dashboard Overview

Upon logging in, the Officer Dashboard serves as the central command screen. It gives real-time visibility over current facility activity and quick access to core guardhouse actions.

  • Real-time Counters: View total visitors today, contractors, deliveries, and currently active guests on site.
  • Register Walk-In Visitor Form: Form on the left side of the dashboard for immediate walk-in registration.
  • Active Visitors List: Right panel showing all currently checked-in guests with checkbox selection and exit controls.

Registering Walk-In Visitors (Primary Guardhouse Duty)

Field IC No: Enter last 4 digits only (e.g. S****5678B)

Registering unannounced walk-in guests, contractors, or delivery personnel is the primary duty of the Security Officer at the entrance post. Below is the real operational workflow simulated using Singapore client sample data.

Phase 1: Input Visitor Details into Registration Panel

Enter the visitor's information. For IC No. / NIK, enter only the last 4 digits (e.g. 5678) for compliance with privacy regulations.

Phase 2: Form Submission & Auto Pass Generation

Upon clicking Register Visitor, the system registers the visitor and automatically routes to the **Digital Visitor Pass** generation page (Pass No: VIS-1623) with printable QR Code.

Phase 3: Live Aggregation in Dashboard Visitor List

Returning to the Officer Dashboard confirms that Tan Wei Ming is now aggregated live at the top of the Visitor List table with Active Status, entry timestamp, and pass number.

Invited Visitor Verification (QR Code / PIN Check-In)

The Verify Visitor page is specifically designed to verify guests who have been pre-invited by Management, Admin, or Residents. Pre-invited visitors already possess a unique QR Code or PIN pass sent to their phone/email prior to arrival.

Method A: Scan QR Code

Ask the visitor to present their digital QR pass on their mobile device. Scan it using the gate optical scanner or camera.

Method B: PIN / Pass Number Lookup

If the visitor presents a numerical PIN or Pass Number (e.g. VIS-1002), type it into the verification bar and press Enter.

Instant Validation: If the QR code or PIN is valid, the system displays a green confirmation, verifies destination details, and registers instant check-in.

Active Visitors & Checkbox Exit Check-Out Procedure

Standard Guardhouse Check-Out Method via Dashboard Table

When visitors depart from the facility, Security Officers process check-outs directly from the Visitor List on the Dashboard. Follow these exact 3 steps:

Step 1
Locate Visitor in Dashboard Table:

Locate the departing visitor's name (e.g. Desmond Lim) in the Active Visitor List table on the Dashboard.

Step 2
Tick Selection Checkbox:

Click the checkbox box located on the left side beside the visitor's name. Ticking the checkbox triggers the action bar showing 1 visitor selected.

Step 3
Click 'Check Out Selected' Button:

Click the red Check Out Selected button on the action bar to confirm check-out and record departure time.

Phase A: Ticking Checkbox Beside Visitor Name (Action Bar Appears)

Selecting the checkbox next to Desmond Lim activates the blue action bar with the red Check Out Selected button.

Phase B: Completed Check-Out Status

After clicking Check Out Selected, the visitor's status updates to Checked Out with departure time archived into official logs.

Batch Check-Out Support: You can tick multiple checkboxes at once to process exit check-out for multiple visitors simultaneously.

Daily Occurrence Book (DOB) & Shift Handovers

Digital Patrol, Facility Incident & Key Management Logging

The Occurrence Book tab provides a digital Daily Occurrence Book (DOB) for security officers to record routine floor patrols, facility incidents, key issuances, and shift handovers with full audit trails.

Step 1
Switch to Occurrence Book Tab:

Click the Occurrence Book tab located beside the Visitor List on the main dashboard to view all recorded logs.

Step 2
Click '+ Log New Occurrence':

Open the entry modal to record category (Patrol, Incident, Key Management, Note), severity level, location, title, and detailed notes.

Step 3
Duty Officer Attribution & Submission:

Upon clicking Submit, select whether the log is entered by the logged-in user or type an officer name. Historical officer names auto-complete automatically.

Phase 1: Daily Occurrence Logs Table View

Displays chronological entries with category badges, severity indicators (Normal, Warning, Critical), duty officer tags, and photo attachments.

Phase 2: Log New Occurrence Modal Form & Verification

Security officers enter event details and verify officer attribution before saving to the central audit record.

Audit Integrity: Every log entry links both the Duty Officer name and the logged-in account username along with an unalterable timestamp for operational compliance.
