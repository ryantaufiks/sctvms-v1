Auto Backup & Recovery

Configure automated backups using Windows Task Scheduler (Option A). Backups are OFF by default and nothing runs unless you enable it and set up the OS task.

Default is OFF. You must also configure a Windows Scheduled Task to execute the backup command.

How to enable auto backup

Linux / Mac (cron)

# Edit crontab
crontab -e

# Add this line (daily at {{ config.backup_time|time:'H:i'|default:'02:00' }}):
{{ config.backup_time|time:'M' }} {{ config.backup_time|time:'H' }} * * * cd {{ BASE_DIR }} && .venv/bin/python manage.py backup_site --site-id 1 --output-dir "{{ config.backup_output_dir|default:'backups' }}" >> logs/backup.log 2>&1

Windows (Task Scheduler)

schtasks /Create /TN "VMS Daily Backup (Site 1)" /SC DAILY /ST {{ config.backup_time|time:'H:i'|default:'02:00' }} /TR ""{{ BASE_DIR }}\.venv\Scripts\python.exe" "{{ BASE_DIR }}\manage.py" backup_site --site-id 1 --output-dir "{{ config.backup_output_dir|default:'backups' }}"" /F

Adjust the site ID and paths as needed. This application stores your preferences and can run backups on demand; scheduling is done via the OS.
